> [!NOTE]
> These dotfiles are tailored for my personal use. They may need adjustments to work for your environment.

## 📚 Essential knowledge

> [!WARNING]
> Dotfiles should only contain **shareable** configuration. System- or security-sensitive settings (e.g., private SSH
> keys, tokens) are **not** included here. All files are meant to be symlinked into the system.

### General structure

```sh
dotfiles           # Interactive CLI — install / update / doctor / help
lib/               # Scripts backing each CLI command
  └─ partials/     # Sourced sub-steps (symlinks, git, dns, hblock, login-shell…)
zsh/               # Shell config (load order below)
  ├─ .zshenv       # Every shell — env vars, XDG paths
  ├─ .zprofile     # Login shells — PATH, locale, nodenv
  ├─ .zshrc        # Interactive shells — sources config.d/, compinit, prompt
  ├─ .zlogin       # Post-login — recompiles shell bytecode in the background
  ├─ config.d/     # Modular config, sourced in order (aliases, options, path, plugins…)
  └─ autoloaded/   # Functions loaded on first use (extract, update)
hammerspoon/       # Window management — keys.lua (bindings) + window_management.lua (logic)
ghostty/           # Terminal config + themes
hblock/            # hblock config — header + allow/deny lists; generates /etc/hosts
bat/  git/  ssh/   # Single-file app configs, symlinked individually
Brewfile           # Tracked Homebrew packages (auto-maintained — see below)
.githooks/         # pre-commit hook: gitleaks secret scan
```

> [!IMPORTANT]
> **Everything is symlinked.** Edit files in this repo, never in `~/.config` or `~`. After adding a new config file, run `dotfiles install` and pick the Symlinks module.

**Things worth knowing:**

- **zsh load order:** `.zshenv` → `.zprofile` (login only) → `.zshrc` (interactive only) → `.zlogin`. Env vars go in `.zshenv`, `PATH` in `.zprofile`, everything else in `config.d/`. `plugins.sh` is sourced last, after `compinit`, on purpose.
- **Don't edit `Brewfile` by hand.** A `brew()` wrapper in `zsh/config.d/aliases.sh` rewrites and re-sorts it on every `brew install` / `brew uninstall`. Pass `--no-bundle` to skip that.
- **Login shell must be Homebrew's zsh** (`dotfiles install` → Login shell). If it stays `/bin/zsh`, the two zsh versions fight over the `.zlogin` bytecode cache.
- **`/etc/hosts` is generated by hblock** from the files in `hblock/`. Custom host entries belong in `hblock/header` — never edit `/etc/hosts` directly. `dotfiles update` refreshes it.
- **Run `dotfiles doctor`** after changes — it verifies symlinks, required tools, login shell, hblock, nodenv, and Hammerspoon.
- **XDG paths:** config in `~/.config` (`$XDG_CONFIG_HOME`), data in `~/.local/share`. New tools should follow this.

## 🚀 Install

Before being able to clone the repo, we first need to setup git.

```sh
xcode-select --install
```

Next, clone this repository. You'll be asked where to clone it into — the repo will always be named `dotfiles`.

```sh
read "PARENT?Clone into (. / ~ / ~/JorgenKrieger): "
PARENT="${PARENT:-$HOME/JorgenKrieger}"
mkdir -p "$PARENT"
git clone https://github.com/JorgenKrieger/dotfiles.git "$PARENT/dotfiles"
cd "$PARENT/dotfiles" && ./dotfiles
```

The `./dotfiles` command will run the installer, from where you can pick what parts you'd like to install.

## 🕵🏻 Privacy

After installing, it's highly recommended to set up your system for increased privacy. [Privacy Guides](https://privacyguides.org) provides instructions, apply whatever seems sensible to the machine.
